Maya 2026 · Industry assessment An agent that watches payroll regulation, detects what changed, and refuses to let a language model do the arithmetic. PythonStreamlitSQLite LLM agentsPDF parsing Open record
Problem
Payroll rules change by jurisdiction without warning. Someone has to read every new bulletin, work out what moved, and price the impact across a workforce. Missing one is a compliance failure.
Build
  • An agent fingerprints each policy source by content hash, notices new versions, pulls them, and splits documents into numbered sections carrying jurisdiction and effective date.
  • A language model compares old and new sections and must quote the text it relied on. Code then verifies every quote appears verbatim in the source, recomputes every figure in exact decimal arithmetic, and cross-checks change type against jurisdiction and category.
  • A finding is only marked ready to approve when 8 conditions pass. Everything else routes to a human with the reason stated. Decisions are written to SQLite and never edited after the fact.
  • The agent runs on a hard 25-step cap across 10 tools, none of which can approve anything.
Result
Matched changes against 80 employee records across 3 jurisdictions, priced wage increases including overtime and employer tax, and shipped a review dashboard with filters, immutable decision history and CSV export.
Takeaway
The division of labour is the whole design. The model reads, the code checks, a person decides.

AutoDDG-Geo 2026 · NYU Tandon research Geospatial datasets describe themselves badly, so nobody finds them. A deterministic profiler fixes what the language model gets wrong. PythonLLMsGeoPandasShapely Open record
Problem
NYC Open Data holds over a thousand datasets with descriptions too vague to search. Handing them to a language model directly produces confident, wrong claims about geometry, which then break everything downstream.
Build
  • Wrote a rule-based profiler that infers spatial role, geometry type and resolution deterministically across 1,000+ datasets. No model involved, so no hallucinated geometry.
  • Fed that structured profile into the language model, which does the part it is actually good at: writing natural language from reliable metadata.
  • Handled the real inputs rather than the clean ones: lat/lon columns, WKT, GeoJSON, geometry stored as strings, missing metadata, and geometries exceeding token limits.
Result
Geo-Faithfulness Score rose from 0.5 to 1.0 across five benchmark datasets, with search precision, recall and MRR each improving by roughly 3%.
